## 三、功能模块详解

### 3.1 职业小镇首页（index.html）
- `renderDoors()` 从 `CAREERS` 动态生成 15 扇门（图标 / 门牌号 / 职业名 / 副标题）。
- 点击门 → `openModal()` 开门动画 → 模态框展示该职业 3 张场景 + 气泡文案轮播。
- 主按钮 `goToTest()` 携带 `career` 参数跳转 test.html。
- 底部 3 点页面指示器可手动切换三个 screen（但 screen-test / screen-report 在此文件中为占位空屏，实际跳转走外部文件）。

### 3.2 天赋觉醒舱（test.html）
- 解析 URL `?career=` 定位职业；无参则回退到第一个职业。
- 6 道单选题，每题 6 个维度之一（logic / expression / aesthetic / empathy / handsOn / physical）。
- 实时进度条、角色表情随答题进度变化、选中卡牌 ✨ 粒子飞散。
- 完成后 `showCompleteOverlay()` 播放升级动画，将 `{careerId, answers, dimensionScores, timestamp}` 存入 localStorage，1.8s 后跳 report.html。

### 3.3 角色面板报告（report.html）
- 读取顺序：URL `?career=` → 回退 localStorage `testResult` → 回退第一个职业。
- `findCareer()` 查不到职业时显示"职业未找到"并 3 秒后跳回首页。
- `calcMatch()` 按用户维度得分（原始 0–20 ×5 标准化为 0–100）与职业 `dimensions` 计算匹配度与星级。
- 渲染英雄卡 / 本命职业卡 / 维度雷达 / 装备推荐 / 推荐专业 / 隐藏副本（艺考路线）。
- 含入场滑入动画、隐藏副本折叠开关 `toggleDungeon()`。

### 3.4 数据层（data.js）
- `CAREERS`：15 个职业，每个含 id / name / emoji / motto / doorColor / doorNum / doorSub / scenes / bubbles / talentWords / matchRate / matchStars / dimensions / equipment / majors / scores / hasArtPath / artPaths。经核对，15 个职业的 motto / dimensions / majors 字段均齐全。
- `QUESTIONS`：6 道题，每题含 id / qNum / text / options（含 dimension 与 score）。

### 3.5 角色系统（character.js）
- `setCharacterMood(mood)`：5 种表情文案（curious/excited/thinking/thrilled/done）。
- `setCharacterHat(emoji)`：报告页给角色戴职业帽子 + 微动效。
- `playLevelUpAnimation()`：升级日志钩子（可扩展粒子/音效）。

### 3.6 样式（style.css）
- 1511 行，含 `.phone` 手机壳、`.door` 门网格、`.modal` 模态框、`.progress-*`、`.choice-card`、`.hero-card`、`.career-card`、星空粒子、入场动画等。无外部字体/图片，纯 CSS + Emoji。

## 四、核心数据流

1. **首页 → 测试**：`career` 通过 URL query 传递。
2. **测试 → 存储**：6 题维度得分累加后写入 `localStorage['testResult']`。
3. **存储 → 报告**：report.html 优先用 URL 参数，缺失时回退 localStorage，再缺失时回退默认职业——三级兜底，健壮性良好。

## 五、运行与部署

- **本地预览（推荐）**：在项目目录起一个静态服务器，例如
  `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。
- **直接打开**：双击 index.html（`file://`）也可运行，但部分浏览器对 `file://` 下的 localStorage 有限制，建议用本地服务器。
- **部署**：纯静态，可直接托管到任意静态空间（GitHub Pages / 对象存储 / WorkBuddy 发布），无需服务端。
- **运行进程**：当前无任何服务在跑；最后修改时间统一为 2026-07-09，约 3 个月未改动。
